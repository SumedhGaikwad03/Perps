# Shared ESLint Config (`packages/eslint-config`)

Shared ESLint configurations used throughout the Perps monorepo:

* `base.js`: Base ESLint configurations for standard TypeScript and JavaScript packages.
* `next.js`: Specific linting rules for Next.js applications (`apps/docs`).
* `react-internal.js`: Linting configurations for React applications and component libraries (`apps/web`, `packages/ui`).
